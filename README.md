
# ✨ Glaze AI

Glaze AI is a fun and interactive AI-powered web application that turns photo uploads into hilarious Malayalam compliments, celebrity comparisons, beauty awards, and crazy troll reactions. 😂✨

## 💡 About the Project

Glaze AI is created to make photo sharing more fun and entertaining. Users can upload a photo and choose different glazing modes to receive exaggerated and funny Malayalam reactions.

The application combines AI, creativity, humor, and an attractive user interface to create a unique photo entertainment experience.

## 🎭 Glazing Modes

- 😊 Cute Mode – Sweet and funny compliments
- 😍 Extra Mode – More exaggerated compliments
- 🔥 Crazy Mode – Extreme celebrity comparisons and trolls
- 💀 No Logic Mode – Completely random and crazy reactions

## 😂 Features

- 📸 Photo upload and preview
- 🤖 AI-style Malayalam compliments
- 🎬 Funny celebrity comparisons
- 💄 Makeup-related jokes
- 🪞 Mirror jokes
- 📱 Instagram-style reactions
- 🏆 Funny beauty awards
- ⚠️ Crazy beauty warnings
- 😂 Random troll punchlines
- ✨ Fun and interactive interface

## 🎯 Purpose

The main goal of Glaze AI is to create a fun and humorous experience where users can upload their photos and enjoy exaggerated compliments and entertaining reactions.
